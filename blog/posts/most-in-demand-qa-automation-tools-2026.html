Selenium vs Playwright vs Cypress

Selenium is still the most requested tool, but Playwright is close behind: 29% vs 25% of job descriptions. Cypress is mentioned in 18%.

  • Selenium is most common in large companies, banks, consultancies and Java-based teams. Many of these jobs maintain big existing test suites.
  • Playwright shows up mostly in product companies and startups that use TypeScript or Python. New test projects often start with Playwright.
  • Cypress is popular in front-end-heavy JavaScript teams. Playwright is now mentioned more often.

Our advice: If you know Selenium, learning Playwright is the best way to widen the jobs you qualify for. If you are just starting out, begin with Playwright and learn enough Selenium to read an existing framework.

Python is the most requested language in QA jobs. JavaScript and TypeScript together appear in more jobs than Java. Java is still common in enterprise automation with Selenium, TestNG and REST Assured.

API, performance and mobile testing

  • API testing: 20% of jobs mention Postman and 9% mention REST Assured. Almost every automation role expects you to test APIs, not only the user interface.
  • Performance testing: JMeter (9.5%) is still the leader. k6 (5.5%) is growing and Gatling (3.1%) is less common. See performance tester jobs.
  • Mobile testing: Appium leads with 9.5%. Native frameworks such as Espresso and XCUITest appear in fewer than 2% of jobs each.

The new skill: testing AI features

One in ten QA job descriptions (10.9%) now mentions AI, LLMs or generative AI. Some of these jobs ask you to test AI features, such as chatbots, recommendations or AI-generated content. Others expect you to use AI tools to write and maintain tests faster. If you have tested an LLM feature, put it on your resume.

CI/CD and cloud skills

Jenkins (12.6%), Docker (11.1%), GitHub Actions (9.6%) and Kubernetes (8.8%) show that QA engineers are expected to run tests inside pipelines, not only on their own laptop. Many employers see setting up tests to run on every pull request as the line between a mid-level and a senior QA engineer.

A practical learning path for 2026

  1. Learn SQL and API testing with Postman. Many manual and analyst roles ask for these too.
  2. Learn Playwright with TypeScript or Python.
  3. Run your tests in GitHub Actions and publish the report.
  4. Add one specialty: performance testing (k6 or JMeter), mobile testing (Appium) or testing AI features.

Methodology

We searched the descriptions of 1,146 open QA and software testing jobs on QA Job Board, collected from company career pages and remote job sources and posted in the last 45 days. Each job is counted once per tool, whether the tool is mentioned once or many times. Percentages show the share of all job descriptions that mention the tool.
